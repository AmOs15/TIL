# Next.js App

###  Next.jsのアプリ構築<br>
`yarn create next-app`<br>
https://nextjs.org/docs/app/getting-started/installation#automatic-installation
<br>
- ESLint とは？
JavaScript/TypeScriptで静的解析を行うライブラリ<br>
構文が、スタイルガイドラインなどの指定したルールに違反してないかをチェックして、指摘・修正してくれたりする仕組み
- Tailwind CSS とは？
CSSフレームワーク
- Turbopack とは？
`next dev` のオプションでローカル開発で立ち上がりが高速になる<br>
https://nextjs.org/docs/app/api-reference/turbopack
- prettier とは？
コードの自動生成を行うツール. コードフォーマッタ<br>
`/frontend/.prettierrc.json`<br>
設定ファイルで詳細な設定を変更できる
